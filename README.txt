                             AllBinary Platform GDScript

What is it?

This repository contains code generated by the AllBinary Platform for support in GDScript.  
This repo is used to allow developers to skip the GDScript code generation step.

What are some example games with this GDScript code?

https://allbinary.itch.io (The downloads with "-gdscript" in the filename are GDScript only builds. Currently that only includes nothing. Also the GDScript builds are not available on Google Play or other stores.)
